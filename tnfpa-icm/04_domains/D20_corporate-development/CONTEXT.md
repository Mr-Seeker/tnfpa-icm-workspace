## Process
1. Copy `D20_corporate-development.xlsx` and `_templates/domain-record/notes.md` into `companies/<slug>/domains/D20_corporate-development/`.
2. Replace the sample rows with the company's data (sheets: Pipeline (type, counterparty, stage, fit, value, probability → risk-weighted value, owner, next step, government touchpoint), Summary). Type only into pale-yellow cells.
3. Recalculate; `Checks` OVERALL must be PASS. Verify any statutory rate against `01_tamil-nadu/verification-register.md`.
4. Apply W00 judgment; set `notes.md` status to `reviewed` after the owner confirms.
5. Transfer the feed values below into the company's K01/K02 copy or memory file and log the transfer in `notes.md`.
