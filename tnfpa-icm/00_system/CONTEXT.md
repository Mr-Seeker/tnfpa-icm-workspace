# 00_system — the rules of the house (factory, stable)

**Job:** hold the operating contract every agent obeys, the record schemas, and the exact no-code
replacement for every openfpa command and function. Nothing here changes per company.

| File | Read it when |
|---|---|
| `operating-contract.md` | first session in this workspace; before any broad company work |
| `guardrails.md` | before reporting a number, changing a model, or promoting anything |
| `no-code-policy.md` | before creating any new file — what file types and formulas are allowed |
| `command-equivalents.md` | you would have run an `openfpa …` command |
| `kernel-equivalents.md` | you would have called a `pyfpa.…` function |
| `status-and-doctor.md` | "where are we?" / before relying on workspace state |
| `setup-questionnaire.md` | first time a new organisation opens the workspace (engine, BI, units, approvers) |
| `naming-and-ids.md` | creating slugs, ids, file names |
| `schemas/` | writing or validating any memory record |
| `coverage/` | auditing that every openfpa file has a replacement |

**Inputs:** none (reference layer). **Outputs:** none. **Human check:** changes to this folder are
method changes — propose them as a decision file in the affected company or here, never silently.
