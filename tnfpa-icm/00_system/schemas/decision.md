# Decision record

**File:** `memory/decisions/<YYYY-MM-DD>-<slug>.md` (the onboarding proposal is
`initial-model-architecture.md`). Frontmatter: `date, decision, decided_by, status (proposed|approved|
rejected|superseded), evidence[]`. Body: context, options considered, decision, consequences, review date.
A gate is passed only when a decision file says `status: approved` with a named human and date (for the
architecture proposal: the "Approved to scaffold" box ticked plus `Approved by: <name>, <date>`).
